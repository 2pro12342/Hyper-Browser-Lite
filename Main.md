# Hyper Browser Lite 
Hyper Browser Lite is build for ChromeOS IWA's (Isolated Web App) featuring normal browser features, but on a IWA. 

## Set-up Guide 
This is a guide on how to set-up IWA's and install Hyper Browser Lite. 

### Requirements (for Method 1)
- IWA unblocked in ChromeOS settings
- Must be on v154 of chrome or above to install IWA's 

### Requirements (for Method 2) 
- Powerwashing unblocked (be able to powerwash)
- A good way to turn off internet manually (phone hotspot recommended)
- No force prolicies enrollment (if says "loading policies" after powerwash & enrolling, you cannot do this)
- Must be on v154 of chrome or above to install IWA's 

### Method 1 
1. Open ChromeOS Settings, not the browser settings.
2. Go to Apps.
3. Click `Turn on isolated web apps` so it's enabled. (if blocked, do method 2)
4. Go to this page's releases and you'll see the download called `Hyper-Browser-Lite.swbn` and download that file.
5. Open file manager and open the `.swbn` file you've downloaded.
6. Click install and the app should load.

### Method 2 (Unblock IWA's option) 
1. Go to this page's releases and you'll see the download called `Hyper-Browser-Lite.swbn` and download that file, but put it in `G-Drive` or use a USB just in case.
2. Sign out and powerwash. (this will reset all data on device, so make sure that device data and device files are backed up and saved; including files in downloads, G-Drive is fine)
3. Enroll until you log in; right before log in there should be a black screen or lag setting up account, IMMEDIATELY manually turn off wifi. (unplug wifi or disconnect phone hotspot)
4. Open ChromeOS Settings, not the browser settings.
5. Go to Apps.
6. Click `Turn on isolated web apps` so it's enabled. (if blocked, redo steps 2 and above)
7. Open file manager and open the `.swbn` file you've downloaded from earlier. (plug in USB if you put it on there)
8. Manually turn on internet & wait for internet to connect, then click install and the app should load.
